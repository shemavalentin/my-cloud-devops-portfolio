## Running Locally

### Prerequisites

- Node.js
- npm
- Git

### Clone the repository

```bash
git clone git@github.com:shemavalentin/my-cloud-devops-portfolio.git
cd my-cloud-devops-portfolio
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

Open your browser and navigate to:

```text
http://localhost:3000
```
